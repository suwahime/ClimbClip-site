# ClimbClip 公開サイト設計

## 目的

ClimbClip の公開情報を掲載する GitHub Pages 用サイトを作成する。
主目的は、Google OAuth の外部向け本番運用に必要な公開情報を、アプリ本体の非公開リポジトリとは分離して提供すること。

## 公開ページ

以下の 3 ページを日本語で提供する。

1. `index.html`
   - ClimbClip の概要
   - Android 向けボルダリング動画撮影・解析アプリであること
   - Google Drive 連携の用途
   - プライバシーポリシー、利用規約へのリンク
   - 問い合わせ先

2. `privacy.html`
   - 取得・利用する情報
   - Google Drive API の利用目的
   - Google Drive へのアクセスはユーザーが明示的に許可した範囲で行うこと
   - 実機解析・診断ログを保存する目的で利用すること
   - Google ユーザーデータを販売しないこと
   - 第三者提供、保存、管理に関する方針
   - ユーザーによるアクセス権の撤回方法
   - ポリシー変更
   - 問い合わせ先

3. `terms.html`
   - 利用条件
   - ユーザーの責任
   - 禁止事項
   - 本サービスの変更・停止
   - 知的財産
   - 免責
   - 規約変更
   - 準拠法
   - 問い合わせ先

## サイト構成

ビルド処理やフレームワークは導入せず、静的ファイルのみで構成する。

```text
/
├── index.html
├── privacy.html
├── terms.html
├── style.css
├── .nojekyll
└── README.md
```

GitHub Pages の Project Site として `main` ブランチのルートを公開する想定とする。

公開 URL は以下を想定する。

- `https://suwahime.github.io/ClimbClip-site/`
- `https://suwahime.github.io/ClimbClip-site/privacy.html`
- `https://suwahime.github.io/ClimbClip-site/terms.html`

## デザイン

- 日本語のみ
- モバイルとデスクトップの両方で読みやすいレスポンシブレイアウト
- JavaScript 不使用
- 外部 CDN・Web フォント不使用
- OS 標準フォントを使用
- 白背景を基調とした簡素な文書サイト
- 3 ページ共通のヘッダーとフッター
- すべてのページからホーム、プライバシーポリシー、利用規約へ移動可能

## Google Drive 連携に関する記載方針

ClimbClip は Google Drive API を、実機解析・診断ログをユーザーの Google Drive に保存する目的で利用する。

現時点の設計では以下を前提とする。

- OAuth scope は `https://www.googleapis.com/auth/drive.file` を使用する。
- Google Picker API を使用して、ユーザーが許可するフォルダを選択する。
- アプリ側では ClimbClip 用の `runs` フォルダを対象として扱う。
- Google Drive 内のデータを広告、販売、プロファイリング等の目的には利用しない。
- Google Drive 連携を利用しない限り、Drive データへアクセスしない。

ただし、アクセストークン等の内部実装詳細については、実装確定前にプライバシーポリシーで不必要に断定しない。

## 利用規約の方針

個人開発アプリ向けの簡潔な規約とし、過度に複雑な商用サービス向け条項は導入しない。

以下は含める。

- 本アプリの利用はユーザー自身の責任で行うこと
- 法令・第三者の権利を侵害する利用を禁止すること
- 機能や提供内容を予告なく変更・停止する場合があること
- アプリの完全性、継続性、特定目的への適合性を保証しないこと
- 利用による損害について、適用法令上許される範囲で責任を制限すること
- 日本法を準拠法とすること

裁判管轄については、運営者の所在地を公開する必要が生じる表現を避けるため、初版では特定の専属的合意管轄を定めない。

## 実装しないもの

初版では以下を実装しない。

- JavaScript
- Cookie / アクセス解析
- 問い合わせフォーム
- ユーザー登録
- 多言語化
- 独自ドメイン設定
- GitHub Actions によるデプロイ

## GitHub Pages

PR マージ後、GitHub リポジトリ設定で Pages の公開元を `main` ブランチの `/ (root)` に設定する。

Pages の有効化そのものはコード変更とは分離する。

## 検証

実装時に以下を確認する。

- 3 ページが有効な HTML として表示できること
- すべての内部リンクが正しいこと
- CSS 参照が Project Site のサブパスでも壊れないこと
- モバイル幅でも横スクロールが発生しないこと
- ページ内に非公開情報やアプリ本体リポジトリへの不要な参照がないこと
- Google Drive の説明が実装予定の `drive.file` + Picker 方針と矛盾しないこと
